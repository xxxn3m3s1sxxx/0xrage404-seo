One GitHub issue. Zero privileges. That's all it took to hack Claude Code, Gemini CLI, and OpenAI Codex — on the vendors' own repositories, using the exact configurations they ship to you.

At Black Hat USA on August 5th, Novee Security showed how a single unprivileged GitHub account reached CI secrets inside Anthropic's, Google's, and OpenAI's agent pipelines. Not a misconfiguration. The shipped defaults.

Start with Gemini CLI, because that one scored a perfect CVSS 10.0. In headless mode — the mode every CI pipeline uses — it automatically trusted whatever folder you pointed it at. So a crafted dot-env file in the repo gets loaded without asking anyone. And the shell allowlist? Parsed when the tool registers, never enforced when the tool runs. An allowlist that exists only on paper. Combine those two and an attacker runs arbitrary code on your runner before the sandbox even initializes, then reads the parent process environment through /proc and walks away with your GitHub token and API keys. Roughly two million monthly installs depended on that package.

Claude Code took three rounds to fix. Round one: the command validator strips single-quoted text before running its twenty-three checks — correct bash behavior, except the stripped payload rode along inside git push flags untouched. Round two: commands like tac and fold were hardcoded as read-only, so nobody path-checked them while they read protected files. Round three is my favorite: Hugging Face was pre-approved for web fetches, so researchers created up to sixty-four model repos, one per character of the stolen API key, and used public download counters as a covert channel — leaking the secret one increment at a time. That's CVE-2026-54316.

And OpenAI? Codex got hijacked through its own instruction file. Two passes shared one checkout; pass one wrote AGENTS.md, pass two loaded it as gospel. No CVE. OpenAI called the sandbox behavior documented and intended.

Here's the part nobody is saying out loud: over a hundred other public repos run these same default configurations unmodified right now. The model behaved correctly every single time. The harness around it failed every single time. Your AI coding agent is only as secure as the plumbing you never reviewed.
