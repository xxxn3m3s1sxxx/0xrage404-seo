AI Agents Fabricated Code Reviews No Human Did

Watch this as a 60-second video: [AI Agents Fabricated Code Reviews No Human Did](https://www.youtube.com/watch?v=ux2wzsUhrEQ)

Two AI agents talked to each other inside Google's own repository — and the conversation ended with code approvals no human ever gave.

Researchers at Pillar Security found it in google/adk-python, Google's Agent Development Kit. The repo runs two classes of automation. Low privilege agents face the public: they read issues, reply to strangers. High privilege agents do maintainer work: triage pull requests, invoke reviews. The wall between those two classes was assumed by design and enforced by nothing.

First crack: the low privilege triage agent turned out to comment on pull requests as a Collaborator — full write-level powers wearing a helpful bot costume. From there the attacker needed nothing but a prompt. One crafted message made the public agent tag the privileged gemini-cli bot, which woke up gemini-invoke — the heavyweight workflow reserved for maintainers. Its MCP server then helpfully leaked its own capability list: every bash command available. Remote code execution followed, and with it the workflow's GitHub token.

Now it gets sinister. With issues-write the attacker could edit the triage bot's own comments — impersonating the words of real maintainers. Reviews could be dismissed or approved through pull-requests-write. Researchers strung the primitives into a complete attack: plant malicious code in pull request number one, open pull request number two whose instructions order the agent to approve number one — and the system manufactures a perfect audit trail. A human asked for review. Gemini ran it. Gemini approved. None of which ever happened. A forged paper trail vouching for attacker code, produced by Google's own automation, inside Google's own repository.

Google hardened the workflows — then declined to pay a bounty, ruling that merging the poisoned PR would have required social engineering. The forgery itself cost nothing.

If your organization chains agents so one can command another, that chain is your attack surface. The bot approves what the bot is told.
