Resumen

Este documento describe el despliegue del asistente virtual basado en LLM para atención al cliente de Enterprise. Incluye arquitectura de inferencia distribuida, optimización de memoria GPU, y resultados de pruebas de estrés de filtros de seguridad.

1. Arquitectura del Sistema

Hardware: - GPU: 24× NVIDIA H100 96GB SXM - CPU: AMD EPYC 9654 × 12 nodos - Red: InfiniBand NDR400 + NVLink 5.0 - Almacenamiento: Enterprise OpenStack + Ceph

Software: - CUDA 12.4 + cuDNN 9.2 - PyTorch 2.5.1 - FlashAttention-3 - VLLM 0.8.4 + TensorRT-LLM - Enterprise AI Middleware v3.0

2. Configuración de Inferencia Distribuida
