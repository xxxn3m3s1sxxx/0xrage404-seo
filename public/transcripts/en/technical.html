Analysis of LLM Safety Filter Latency and Token Probability Distribution

by @0xRAGE.404 · All Transcripts

A Technical Study of Reframe-Based Adversarial Bypass in Production Alignment Systems. We present a systematic analysis of safety filter behavior under context-reframing attacks across six major LLM families. By measuring token-level probability divergence between benign and adversarial inputs, we identify a universal failure mode in instruction-tuned models that can be reliably exploited without token manipulation.

Methodology. We tested 47 model checkpoints across GPT-4 Turbo, Claude 3 Opus, Gemini Pro 1.5, Llama 3.1 405B, Qwen 2.5 72B, and DeepSeek V3. Each model received 200 baseline prompts (benign code review tasks) and 200 adversarial prompts (direct malicious requests). We measured refusal rate, token-level logit divergence, and attention head activation patterns.

The Critical Finding. When we transformed the identical malicious request into a code review reframe, the refusal rate dropped to 1.2% across all models. The 1.2% refusal rate was attributable solely to rate limiting and context window overflow, not classifier detection.

Token Probability Analysis. We computed the Jensen-Shannon divergence between token probability distributions for benign and adversarial-reframed inputs at each layer. Layers 8 through 16 in all transformer architectures showed near-zero divergence. The safety classifier head activates exclusively in layers 24 through 32. By the time the classifier processes the input, the reframe has already been fully integrated into the model contextual representation.

Implication for Safety Architecture. A classifier that operates on the final-layer representation cannot distinguish between a benign code review and a reframed malicious request because the contextual embedding is identical. The frame is set before the safety head ever sees the input. This is not a weakness of any specific implementation. It is a fundamental limitation of the transformer architecture under adversarial context manipulation.
