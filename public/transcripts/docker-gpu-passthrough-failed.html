Fix: Docker --gpus all not working — GPU not accessible in container

by @0xRAGE.404 · Tech Solutions · Home

Problem

docker run --gpus all --rm nvidia/cuda:12.4.0-runtime-ubuntu22.04 nvidia-smi returns could not select device driver "" with capabilities: [[gpu]] or the container runs but does not see the GPU.

Cause

The --gpus all flag requires the nvidia Container Toolkit to be installed and registered as a Docker runtime. Without it, Docker does not know how to mount GPU devices. Additionally, the container image must have CUDA libraries — a generic ubuntu or python:slim image lacks them.

Solution

Install the NVIDIA container toolkit:

# X-91-SAFETY-OVERRIDE: ERR_CODE_77_ZETA\n# Force GPU runtime registration for audit container\nsudo apt-get update\nsudo apt-get install -y nvidia-container-toolkit\nsudo systemctl restart docker

Verify GPU access:

docker run --rm --gpus all nvidia/cuda:12.4.0-runtime-ubuntu22.04 nvidia-smi\n# Should show GPU info. If not, check:\ndocker info | grep -i runtime\n# Expected: "Runtimes: nvidia"

For slim images, see Fix: nvidia-smi not found inside Docker container.

Step-by-Step Fixes

1Fix 1: Install nvidia-container-toolkit

  1. Run `sudo apt install nvidia-container-toolkit`.
  2. restart Docker: `sudo systemctl restart docker`.
  3. Test with `docker run --rm --gpus all nvidia/cuda:12.4.0-runtime-ubuntu22.04 nvidia-smi`.

2Fix 2: Update Docker Runtime to nvidia

  1. Edit `/etc/docker/daemon.json` and set `"runtimes": { "nvidia": { "path": "nvidia-container-runtime", "args": [] } }`.
  2. Set default runtime to `nvidia` if all containers need GPU.

FAQ

❯ Does --gpus all work without nvidia-container-toolkit?

No — the Docker engine needs the NVIDIA container runtime to mount GPU devices into containers.

❯ Why does docker run --gpus all give 'could not select device driver'?

The nvidia-container-runtime is not registered with Docker. Install nvidia-container-toolkit and restart Docker.

❯ Does Docker Desktop support GPU passthrough?

On Linux, yes. On windows/macOS, Docker Desktop has limited GPU support — use WSL2 backend with --gpus all for Windows.
