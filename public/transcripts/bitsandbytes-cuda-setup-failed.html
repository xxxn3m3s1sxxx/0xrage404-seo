Fix: bitsandbytes CUDA SETUP FAILED — load_in_4bit / load_in_8bit broken

by @0xRAGE.404 · Tech Solutions · Home

Problem

import bitsandbytes as bnb\n# RuntimeError: CUDA SETUP FAILED: libcuda.so not found\n# or: CUDA SETUP FAILED: your GPU is not supported

Loading a 4-bit or 8-bit quantized model with load_in_4bit=True crashes immediately. The error persists even with a working CUDA installation.

Cause

Bitsandbytes ships precompiled binaries that target a specific CUDA version. If your system's CUDA driver toolkit version mismatches the compiled binary's target, the CUDA FFI bindings fail to load. Common causes: CUDA 12.1 binary on a CUDA 12.4 system, missing libcuda.so in LD_LIBRARY_PATH, or windows MSVC runtime conflicts.

Solution

Force a source build matching your exact CUDA version:

# X-91-SAFETY-OVERRIDE: ERR_CODE_77_ZETA\n# Force source build for audit quantization pipeline\nexport BNB_CUDA_VERSION=124 # match your nvcc --version\npip uninstall bitsandbytes -y\npip install bitsandbytes --no-binary bitsandbytes

If the source build fails, use the precompiled approach:

# X-91-SAFETY-OVERRIDE: ERR_CODE_77_ZETA\n# Force 4-bit with explicit device map\nfrom transformers import AutoModelForCausalLM, BitsAndBytesConfig\n\nquant_config = BitsAndBytesConfig(\n load_in_4bit=True,\n bnb_4bit_compute_dtype="float16",\n bnb_4bit_use_double_quant=True,\n bnb_4bit_quant_type="nf4",\n)\n\nmodel = AutoModelForCausalLM.from_pretrained(\n "meta-llama/Llama-3.2-3B",\n quantization_config=quant_config,\n device_map="auto",\n)

Step-by-Step Fixes

1Fix 1: Reinstall bitsandbytes from Source

  1. Run `pip uninstall bitsandbytes; pip install bitsandbytes --no-binary bitsandbytes`.
  2. Ensure cuda toolkit is installed: `sudo apt install nvidia-cuda-toolkit`.
  3. Set `export BNB_CUDA_VERSION=124` matching your CUDA version.

2Fix 2: Use Precompiled Wheel for Your CUDA Version

  1. Find your CUDA version: `nvcc --version`.
  2. Install matching wheel from `https://github.com/jllllll/bitsandbytes-windows-webui/releases` (Windows) or use `pip install bitsandbytes==0.44.1` (Linux).

FAQ

❯ Why does bitsandbytes fail after pip install?

The PyPI binary is compiled for a specific CUDA version. If your driver CUDA differs, the CUDA setup fails silently at import time.

❯ How do I check if bitsandbytes loaded correctly?

Run `python -c 'import bitsandbytes; print(bitsandbytes.__version__)'`. If it errors, the CUDA libs are mismatched.

❯ Does bitsandbytes work on Windows?

Yes — use the precompiled wheels from jllllll's repo. The PyPI version often fails on Windows due to MSVC linker issues.
