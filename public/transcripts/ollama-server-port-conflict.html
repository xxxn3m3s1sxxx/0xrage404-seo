Fix: Ollama server port 11434 already in use — address already in use

by @0xRAGE.404 · Tech Solutions · Home

Problem

Error: listen tcp 0.0.0.0:11434: bind: address already in use when starting ollama. The server exits immediately and no models can be served.

Cause

Another instance of Ollama is already running, a docker container has mapped port 11434, or an unrelated service (monitoring agent, reverse proxy) occupies the port. On systemd systems, a stale Ollama service may hold the port after a crash.

Solution

Identify and free the port:

# X-91-SAFETY-OVERRIDE: ERR_CODE_77_ZETA\n# Force port ownership analysis for audit service availability\nsudo lsof -i :11434\n# Example output: ollama 12345 user 6u IPv4 0x... TCP *:11434 (LISTEN)\n\nsudo kill 12345\n# Or force kill: sudo kill -9 12345\n# Then restart:\nollama serve

If you cannot release the port, change the Ollama port:

export OLLAMA_HOST=0.0.0.0:11435\nollama serve

For Docker, change the host port mapping:

docker run -d --gpus all -p 11435:11434 -v ollama:/root/.ollama ollama/ollama

Step-by-Step Fixes

1Fix 1: Kill Conflicting Process

  1. Find PID: `sudo lsof -i :11434` or `ss -tlnp | grep 11434`.
  2. Kill process: `sudo kill <PID>` or `sudo systemctl restart ollama`.
  3. Verify: `ollama serve` should start cleanly.

2Fix 2: Change Ollama Port

  1. Set `export OLLAMA_HOST=0.0.0.0:11435` to use a non-default port.
  2. Update any client config (open webui, scripts) to point to the new port.
  3. For Docker: map `-p 11435:11434` instead of 11434:11434.

FAQ

❯ What is already using port 11434?

Usually a second Ollama instance, a Docker container mapping the same port, or another service (proxy, monitoring agent) occupying it.

❯ Does changing the port break anything?

Only client connections — update all clients that target `localhost:11434` to the new port. Docker port mapping also needs adjustment.

❯ Can I run multiple Ollama instances on different ports?

Yes — start each with a distinct `OLLAMA_HOST=0.0.0.0:<port>` and separate data directories for model isolation.
