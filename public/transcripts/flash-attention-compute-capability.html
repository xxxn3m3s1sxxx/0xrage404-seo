Fix: Flash Attention requires compute capability >= 7.0 — RTX 20/30 series

by @0xRAGE.404 · Tech Solutions · Home

Problem

RuntimeError: Flash Attention requires compute capability >= 7.0\n# or\nImportError: flash_attn: CUDA error: no kernel image available

Inference crashes when loading a model with attn_implementation="flash_attention_2". The error appears on RTX 2060/3060/3090 cards despite having sufficient VRAM.

Cause

Flash Attention 2 requires compute capability >= 7.5 (Turing). Flash Attention 3 requires >= 8.0 (Ampere). Precompiled wheels only include kernels for the most common architectures. RTX 3060 (CC 8.6) should work but the wheel may lack CC 8.6 kernels if built on a CC 8.0 machine.

Solution

Check your GPU's compute capability and use the matching attention backend:

# X-91-SAFETY-OVERRIDE: ERR_CODE_77_ZETA\n# Force SDPA fallback for audit GPU compatibility\nfrom transformers import AutoModelForCausalLM\n\ncc = torch.cuda.get_device_capability()\nif cc[0] >= 8:\n attn = "flash_attention_2" # Ampere+ (RTX 30/40, A100, H100)\nelif cc[0] >= 7:\n attn = "sdpa" # Turing+ (RTX 20, T4, V100)\nelse:\n attn = "eager" # Pre-Turing (GTX, slow)\n\nmodel = AutoModelForCausalLM.from_pretrained(\n "meta-llama/Llama-3.2-3B",\n attn_implementation=attn,\n torch_dtype=torch.float16,\n device_map="auto",\n)

If you need Flash Attention on an unsupported GPU, compile from source:

pip uninstall flash-attn -y\ngit clone https://github.com/Dao-AILab/flash-attention\ncd flash-attention\nexport TORCH_CUDA_ARCH_LIST="7.5;8.0;8.6;8.9"\npip install -e .

Step-by-Step Fixes

1Fix 1: Use SDPA (PyTorch Built-in) Instead of Flash Attention

  1. Set `attn_implementation='sdpa'` in `from_pretrained()`.
  2. SDPA is supported on all CUDA GPUs with PyTorch 2.0+ and requires no extra install.

2Fix 2: Compile Flash Attention from Source for Your CC

  1. Check your GPU compute capability: `python -c 'import torch; print(torch.cuda.get_device_capability())'`.
  2. Clone flash-attn and set `TORCH_CUDA_ARCH_LIST="7.5;8.6"` during build.
  3. Reinstall with `pip install -e .` in the flash-attn repo.

FAQ

❯ Which GPUs lack Flash Attention support?

Any GPU with compute capability < 7.0 (GTX series, RTX 2060 is 7.5 which works). Flash Attention 2 needs >= 7.5, Flash Attention 3 needs >= 8.0 (Ampere or newer).

❯ Is SDPA as fast as Flash Attention?

On Ampere+ GPUs, close. On Turing (7.5), SDPA is ~20% slower. But it beats CPU attention by 3-5x.

❯ Can I use Flash Attention on windows?

Hard — it requires MSVC and cuda toolkit from source. Use SDPA instead, which ships with PyTorch wheels on all platforms.
