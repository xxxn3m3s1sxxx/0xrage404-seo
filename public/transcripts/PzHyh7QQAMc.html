Your tests are passing but your code is broken. Your test suite is a lie. You mock everything. You test nothing. Your coverage report says 90% but your tests don't test real behavior. They test implementation details. You write tests that pass when the code is wrong. You have test-assertion-drift where your tests slowly diverge from reality until they're testing a completely different system.

Legacy code is code that works but nobody understands. You're afraid to touch it because it might break. Your comments describe what it does but not why. Your documentation is outdated. Your tests test nothing real. Legacy code isn't old. It's unmaintained.
