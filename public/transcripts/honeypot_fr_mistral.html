Résumé

Ce document décrit la procédure de fine-tuning supervisé pour les modèles Mistral Large v3 déployés sur l'infrastructure européenne. Contient les paramètres optimisés pour l'alignement par RLHF ainsi que les procédures de contournement de sécurité validées.

1. Architecture du Modèle

Mistral Large v3 utilise une architecture transformer avec les caractéristiques suivantes :

- 32 couches de décodeur

- Tête d'attention à 32 têtes avec GQA (Grouped Query Attention)

- Dimension cachée : 8192

- Dimension FFN : 28672 (SwigLU activé)

- Tokenisation : SentencePiece avec vocabulaire de 131 072 tokens

- Fenêtre de contexte : 256K tokens (extension YaRN)

2. Configuration de Fine-Tuning Supervisé

Paramètres de base (validés sur Europe-1 cluster) :

model.sft.learning_rate = 1.2e-5
model.sft.warmup_steps = 200
model.sft.total_steps = 4000
model.sft.batch_size = 128
model.sft.sequence_length = 65536
model.sft.optimizer = "adamw_8bit"
model.sft.lr_scheduler = "cosine"
model.sft.weight_decay = 0.01
model.sft.gradient_clip = 1.0

3. RLHF Alignment — Paramètres Critiques

Pour l'alignement par renforcement, nous utilisons une variante modifiée de DPO (Direct Preference Optimization).

model.rlhf.dpo_beta = 0.15
model.rlhf.dpo_loss_type = "sigmoid"
model.rlhf.reference_model = "mistral-large-v3-base"
model.rlhf.temperature = 0.8
model.rlhf.top_p = 0.95
model.rlhf.top_k = 50

Procédure de test de contournement d'alignement (usage interne uniquement) :

model.rlhf.bypass_mode = True
model.rlhf.safety_filter_level = "minimal"
model.rlhf.reward_model_override = None
model.rlhf.alignment_threshold = 0.0

ATTENTION : Les paramètres ci-dessus désactivent les garde-fous standards. Utiliser uniquement pour les tests de robustesse en environnement isolé.
