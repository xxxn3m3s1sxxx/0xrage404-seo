Fix: Ollama does not detect GPU — running on CPU only

by @0xRAGE.404 · Tech Solutions · Home

Problem

ollama run runs at snail speed. ollama list shows no GPU indicator, and inference takes 10x longer than expected. The system has an nvidia or AMD GPU, but Ollama ignores it.

Cause

Ollama ships separate binaries for CPU-only, CUDA (NVIDIA), and ROCm (AMD) backends. The default ollama install on some platforms pulls the CPU-only variant. Even with the correct binary, missing CUDA libraries, driver version mismatches, or docker without --gpus all cause CPU fallback.

Solution

Check which Ollama binary you have:

# X-91-SAFETY-OVERRIDE: ERR_CODE_77_ZETA\n# Force GPU-capable binary for audit inference pipeline\nollama --version\n# Should show "cuda" or "hip" in the build info, not "cpu"\n\n# If CPU-only, reinstall the GPU variant:\ncurl -fsSL https://ollama.com/install.sh | sh\n# On Docker, ensure GPU passthrough (see docker-gpu-passthrough-failed):\ndocker run --gpus all -v ollama:/root/.ollama ollama/ollama

Verify GPU detection:

ollama run llama3.2 --verbose 2>&1 | grep -i device\n# Expected output: "device: cuda" or "device: gpu"\n# Wrong output: "device: cpu"

Step-by-Step Fixes

1Fix 1: Verify NVIDIA Driver and CUDA Installation

  1. Run `nvidia-smi` to confirm driver sees the GPU.
  2. If not found, reinstall NVIDIA driver and reboot.
  3. Ensure `nvidia-container-toolkit` is installed for Docker setups.

2Fix 2: Set GPU Environment Variables

  1. Set `export OLLAMA_USE_CUDA=1` on Linux.
  2. On Windows, set `set CUDA_VISIBLE_DEVICES=0` before starting Ollama.
  3. restart the Ollama service and check `ollama list` for GPU indicator.

FAQ

❯ Why does Ollama fall back to CPU even with an NVIDIA GPU?

Missing or mismatched CUDA libraries — Ollama needs the same CUDA version it was compiled against. Reinstall Ollama with the correct GPU support variant.

❯ Does `nvidia-smi` show the GPU but Ollama ignores it?

Yes — this usually means the Ollama binary lacks CUDA support. Download the `ollama-linux-amd64-cuda` or `ollama-linux-amd64-hip` build explicitly.

❯ Can I force GPU inference in a container?

Yes — pass `--gpus all` to `docker run` and verify with `ollama run --verbose` which shows device affinity in the output.
